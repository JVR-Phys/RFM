2. Guía de Instrucciones Paso a Paso

Paso 1: Todo Ordenado

Aplica un estilo uniforme a todo tu trabajo:

  1. Presiona Ctrl + E para seleccionar absolutamente todo el texto del documento.
  2. Presiona Ctrl + J para justificar los párrafos y alinearlos perfectamente a los bordes.

Paso 2: El Gran Título

Dale diseño al título principal del universo que se encuentra al inicio:

  1. Selecciona el título "los misterios del universo y el sistema solar".
  2. Presiona Ctrl + T para centrarlo en la hoja.
  3. Presiona Ctrl + N para ponerlo en letras Negritas.
  4. Presiona la combinación Ctrl + Shift + > tres veces seguidas para agrandar su tamaño.

Paso 3: Estilo a los Subtítulos

Dale jerarquía a tus dos temas principales para que resalten:

  1. Busca el texto "el sol: nuestra gran estrella", selecciónalo y presiona Ctrl + N (Negrita) junto con Ctrl + K (Cursiva).
  2. Busca el texto "los planetas vecinos", selecciónalo y presiona Ctrl + N (Negrita) junto con Ctrl + S (Subrayado).

Paso 4: Nueva Hoja (Salto de Página)

Aprende a pasar a la siguiente página de forma profesional:

  1. Mueve el cursor del mouse y haz un clic justo al final del párrafo de "los planetas vecinos".
  2. Presiona la combinación Ctrl + Enter para crear un salto de página y saltar directamente a una hoja limpia.

🛸 Paso 5: Reto de Ortografía

Un extraterrestre saboteó la nave y alteró el orden de la escritura. ¡Debes solucionarlo con el asistente virtual!

  1. Copia el párrafo afectado que se muestra en la sección de abajo y pégalo en tu nueva hoja limpia de Word.
  2. Coloca el cursor del texto justo al inicio de ese párrafo dañado.
  3. Presiona la tecla de función F7 en tu teclado para abrir el Asistente de Ortografía de Word.
  4. Corrige todas las palabras que la computadora te marque con errores hasta dejarlo perfecto.

📄 Paso 6: El Cierre y Guardado Final

Completa la investigación uniendo las piezas que faltan en tu documento:

  1. Selecciona con el mouse el texto de la "Conclusión del Viaje Espacial" que está al final de esta página web.
  2. Presiona Ctrl + C para copiarlo a la memoria de la computadora.
  3. Regresa a tu archivo de Word, ve al final y presiona Ctrl + V para pegarlo.
  4. Presiona la tecla de función F12 para abrir la ventana de "Guardar Como" y guárdalo con el nombre: Proyecto_Espacio_TuNombre.
